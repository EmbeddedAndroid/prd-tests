# Eliza results from the per-area harness

These are the requirement tables as they stood before the repository
became generic (commit 2ae2b67): one README per area with the latest
result of each requirement, measured with the per-area scripts
(audio/scripts, video/scripts, display/dp, common/lava) that the runner
replaced. The scripts they name are in the git history at that commit;
the audio shell cases are unchanged under tests/audio/test-definitions
and run through the runner with the parameters in boards/eliza-evk.yaml.
Current results are in results/eliza.md.
