# Video

Tests for the Eliza video requirements on the open stack: upstream
qcom-iris (V4L2 stateful decoder and encoder), firmware vpu33_p2_s7 from
linux-firmware, GStreamer 1.28 v4l2 elements and FFmpeg v4l2m2m, on the
meta-qcom `qcom-multimedia-image` for `eliza-evk-emmc-open-fw`, FP
QCDFP-261119-1770 (kernel 7.3.0, qcom-next base). This is an assessment:
the probes inventory the formats and controls the driver exposes and run
short decode and encode checks; they never change the image.

## Layout

| path | what |
|---|---|
| `scripts/video-probe.sh` | main probe: decoder/encoder formats and controls, decode of public conformance vectors, encode round trips, controls in use, concurrency, streaming over localhost (the revision that ran in 590112; 590056 and 590109 ran earlier revisions of it) |
| `scripts/video-probe-v4.sh` | follow-up: encoder stream labelling (profile/level), raw/RTP/HLS decode, B-frames, encoder downscale through V4L2, FFmpeg (590161) |
| `scripts/video-probe-v5.sh` | follow-up: the GStreamer colorimetry refusal and its override (590173) |
| `scripts/stage-overlay.sh` | builds the `/video-prd` overlay tar: a probe as `video-probe.sh` plus the public vectors (AOM AV1 8/10-bit quantizer, libvpx VP9 tile 4x4, JCT-VC WPP_A_ericsson_MAIN10_2) with expected frame counts |
| `scripts/mk-video-job.py` | writes the LAVA job (shared open-boot template, probe from the overlay) and its stock restore backstop |

Every case reports through `lava-test-case` and nothing stops the LAVA
shell; the probes write only under /tmp.

## How to run

    sh scripts/stage-overlay.sh /tmp/vp scripts/video-probe.sh          # needs curl, unzip, python3
    # (follow-ups: scripts/stage-overlay.sh /tmp/vp4 scripts/video-probe-v4.sh --no-vectors)
    # upload /tmp/vp/video-prd-overlay.tar, then:
    export IMAGE_URL=... OVERLAY_URL=... ROOT_PW=...
    export STOCK_IMAGE_URL=... STOCK_IMAGE_DIR=... STOCK_UEFI_VERSION=...
    python3 scripts/mk-video-job.py vp <FP> <device> jobs
    lavacli jobs submit jobs/vp.yaml; lavacli jobs submit jobs/vp-backstop.yaml

Placeholders and environment variables are in the top-level README.

## Known defects found by these probes

- GStreamer v4l2h264dec/v4l2h265dec refuse streams whose VUI maps to
  colorimetry 2:4:5:4 (BT.601 matrix and primaries with BT.709 transfer,
  what the iris encoder writes for a bt601 source): raw Annex-B, RTP and
  MPEG-TS/HLS fail not-negotiated while MP4 works. Overriding the caps
  with `capssetter caps="video/x-h264,colorimetry=(string)bt601"` gives
  60/60 raw, 90/90 RTP, 90/90 HLS ([590173](https://lava.infra.foundries.io/scheduler/job/590173)).
- GStreamer v4l2h264enc without profile/level caps labels a 720p30 stream
  Baseline level 1.0; with `profile=high,level=4` caps it is High L4.0
  ([590161](https://lava.infra.foundries.io/scheduler/job/590161)); iris
  honours the request.
